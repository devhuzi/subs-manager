# Enable Cross-Tool Support

User-invocable. Run when the user wants to use this project with tools
other than Claude Code. Run at onboarding (called by `/onboard` if the
user said yes to Q8) OR mid-project (called directly when the user
decides later).

CLAUDE.md is canonical. The generated files exist purely as views into
CLAUDE.md for tools that don't read it.

## Pre-flight

1. Verify `CLAUDE.md` exists at the project root. If not, refuse and
   tell the user to run `/onboard` first.
2. Detect what's already enabled:
   - Look for `AGENTS.md`, `GEMINI.md`, `.cursor/rules/project.mdc`
   - Look for `tools/sync-agent-files.sh` and the pre-commit hook
3. If nothing exists yet, this is a fresh enable. If some exist, the
   user is adding tools incrementally — preserve what's already there.

## Ask which tools

Use AskUserQuestion (multiSelect = true). Show current state next to
each option:

- **OpenAI Codex** — generates `AGENTS.md`
- **Cursor** — uses `AGENTS.md` (newer versions) and optionally
  `.cursor/rules/project.mdc` (sub-question if Cursor selected)
- **Windsurf** — uses `AGENTS.md`
- **Aider** — uses `AGENTS.md`
- **Gemini CLI** — generates `GEMINI.md`

Note that AGENTS.md covers Codex, Cursor, Windsurf, and Aider — picking
any one of them means generating AGENTS.md once.

## Generate

For each unique target file, write:

### AGENTS.md (if Codex/Cursor/Windsurf/Aider chosen)

```
<!-- Generated from CLAUDE.md by /enable-cross-tool — do not edit directly. -->
<!-- Edit CLAUDE.md instead; the pre-commit hook regenerates this file. -->

[full content of CLAUDE.md, with @import lines resolved inline]
```

### GEMINI.md (if Gemini chosen)

Same format and content as AGENTS.md, just a different filename.

### .cursor/rules/project.mdc (if Cursor + native rules chosen)

Cursor's `.mdc` format is markdown with optional YAML frontmatter:

```
---
description: Project rules for [project name]
globs: ["**/*"]
alwaysApply: true
---

[full content of CLAUDE.md, with @import lines resolved inline]
```

### Resolving `@imports`

When generating, replace any `@.claude/rules/*.md` lines in CLAUDE.md
with the full text of the imported file. Other tools don't follow
`@import` syntax.

## Install sync script

Create `tools/sync-agent-files.sh` (POSIX bash, works on Windows Git Bash):

```bash
#!/usr/bin/env bash
# Regenerates cross-tool agent files from CLAUDE.md.
# Generated by /enable-cross-tool — edit if you need to add a target.

set -euo pipefail

ROOT="$(cd "$(dirname "$0")/.." && pwd)"
SOURCE="$ROOT/CLAUDE.md"

if [ ! -f "$SOURCE" ]; then
  echo "CLAUDE.md not found at $SOURCE" >&2
  exit 1
fi

resolve_imports() {
  local file="$1"
  while IFS= read -r line; do
    if [[ "$line" =~ ^@(.+\.md)$ ]]; then
      local imp="${BASH_REMATCH[1]}"
      if [ -f "$ROOT/$imp" ]; then
        echo ""
        echo "<!-- inlined from $imp -->"
        resolve_imports "$ROOT/$imp"
      else
        echo "$line"
      fi
    else
      echo "$line"
    fi
  done < "$file"
}

write_with_header() {
  local target="$1"
  {
    echo "<!-- Generated from CLAUDE.md by tools/sync-agent-files.sh — do not edit directly. -->"
    echo "<!-- Edit CLAUDE.md instead; the pre-commit hook regenerates this file. -->"
    echo ""
    resolve_imports "$SOURCE"
  } > "$target"
}

# Targets are detected by which files already exist.
[ -f "$ROOT/AGENTS.md" ] && write_with_header "$ROOT/AGENTS.md" && echo "  regenerated AGENTS.md"
[ -f "$ROOT/GEMINI.md" ] && write_with_header "$ROOT/GEMINI.md" && echo "  regenerated GEMINI.md"
if [ -f "$ROOT/.cursor/rules/project.mdc" ]; then
  {
    echo "---"
    echo "description: Project rules"
    echo "globs: [\"**/*\"]"
    echo "alwaysApply: true"
    echo "---"
    echo ""
    resolve_imports "$SOURCE"
  } > "$ROOT/.cursor/rules/project.mdc"
  echo "  regenerated .cursor/rules/project.mdc"
fi

echo "sync-agent-files.sh: done"
```

Make it executable: `chmod +x tools/sync-agent-files.sh`.

## Install pre-commit hook

Create `tools/install-git-hooks.sh`:

```bash
#!/usr/bin/env bash
# Installs the pre-commit hook that regenerates cross-tool agent files
# whenever CLAUDE.md changes.
set -euo pipefail

ROOT="$(cd "$(dirname "$0")/.." && pwd)"
HOOK="$ROOT/.git/hooks/pre-commit"

if [ ! -d "$ROOT/.git" ]; then
  echo "Not a git repo. Run 'git init' first." >&2
  exit 1
fi

cat > "$HOOK" <<'EOF'
#!/usr/bin/env bash
# Auto-regenerate cross-tool agent files when CLAUDE.md is staged.
set -euo pipefail
ROOT="$(git rev-parse --show-toplevel)"
if git diff --cached --name-only | grep -qx "CLAUDE.md"; then
  bash "$ROOT/tools/sync-agent-files.sh"
  # Re-stage any regenerated files
  for f in AGENTS.md GEMINI.md .cursor/rules/project.mdc; do
    [ -f "$ROOT/$f" ] && git add "$ROOT/$f"
  done
fi
EOF
chmod +x "$HOOK"
echo "Installed pre-commit hook at $HOOK"
```

Make it executable: `chmod +x tools/install-git-hooks.sh`.

Then run it once: `bash tools/install-git-hooks.sh`. (Skip if not in a
git repo yet — tell the user to install the hook after `git init`.)

## Idempotency

Re-running this skill must be safe. If the user already enabled Codex
and now wants to add Gemini:
- Detect existing AGENTS.md → don't ask about Codex/Cursor/Windsurf/Aider
  again, just confirm "AGENTS.md already exists, regenerating to refresh"
- Ask about Gemini only
- Generate GEMINI.md, leave others untouched
- Hook and sync script: re-run installer, it overwrites identically

## What you do NOT do

- Don't generate files for tools the user didn't pick.
- Don't modify CLAUDE.md — it's the source.
- Don't delete generated files. Use `/disable-cross-tool` for that.
- Don't run `git add` or commit. Just generate and let the user commit.
